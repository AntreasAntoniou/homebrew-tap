# Cliphoard for Homebrew

Install Cliphoard, a free, open-source clipboard manager for macOS:

```sh
brew install --cask antreasantoniou/tap/cliphoard
```

Requires macOS 13 Ventura or later. The release includes Intel and Apple silicon binaries.

This tap downloads the company-signed, notarized Cliphoard release from [GitHub Releases](https://github.com/AntreasAntoniou/cliphoard/releases). Homebrew verifies the frozen DMG checksum before installation.

[Website and support](https://cliphoard.dev/) · [Application source](https://github.com/AntreasAntoniou/cliphoard)
